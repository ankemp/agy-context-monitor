# Antigravity Context Monitor

A plugin for Antigravity that tracks and reports on context usage and token consumption during interactions with the agent. It hooks into the agent runtime to provide granular context utilization metrics.

## Setup

This plugin can be seamlessly installed into Antigravity using a symlink to continue development while it's active.

```bash
# If not already symlinked:
ln -s ~/Workspace/agy-context-monitor ~/.gemini/config/plugins/context-monitor
```
